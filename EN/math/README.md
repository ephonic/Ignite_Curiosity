# Igniting the Mathematical Spark

*A Tour of Mathematics for Middle School Students*

English translation of the [Chinese mathematics edition](../../math/README.md).
See [the English edition README](../README.md) for the source commit and update workflow.

Translation is in progress. This directory is not yet a complete English
edition, and no complete English PDF is being published. The partial checker
below reports current chapter coverage as work advances.

The English LaTeX sources retain the original document class, fonts, page
geometry, packages, theorem environments, box styles, table column definitions,
and TikZ drawing settings. Printed labels are localized into English.

## Validation and compilation

Run the completeness check from the repository root before a release build:

```sh
python3 scripts/check_english.py math
```

This deliberately fails until every mathematics source is translated. To check
only the existing translations during development:

```sh
python3 scripts/check_english.py math --partial
```

Compile `latex/main.tex` with XeLaTeX, as in the Chinese edition. The required
fonts are Noto Serif CJK SC, Noto Sans CJK SC, and Noto Sans Mono CJK SC.
Run XeLaTeX enough times to resolve the contents and references, or use
`latexmk -xelatex -halt-on-error main.tex` inside `latex/`.

Tectonic, which uses the XeTeX engine and handles repeat passes, is also supported:

```sh
python3 scripts/build_english.py math --publish
```

LaTeX can silently skip missing `\include` files and still produce a PDF.
The source and log checks prevent such a preview from being mistaken for a
complete edition. Structural checks do not replace proofreading or visual PDF
review. Build previews are development artifacts, not finished books.

## Editorial notes

The Chinese text in chapter 2 calls the completing-square term “half the square”
of the linear coefficient, while its displayed formula correctly uses the square
of half the coefficient. The English prose follows the existing formula.
The equations and diagram coordinates themselves are retained, including any
issues already present in the source; this translation is not a mathematical
revision of the books.

For example, chapter 2's first graph draws a line whose endpoints do not lie on
the labeled equation `y = 0.4x + 4`, and its leftmost point label overlaps the
vertical-axis label. These are present in the Chinese TikZ source and have not
been redesigned in the translation.

## Disclaimer

The original book's text was generated by AI, with the human contributor
providing prompts and token costs, followed by human selection and editing.
Errors and omissions are possible. Check important conclusions against standard
textbooks. See the [repository README](../../README.md).
