## 这本书想做什么

这不是把语文、历史、政治、美术课重新装订在一起，而是追踪几个贯穿人类历史的问题：

- 人类为什么需要语言，语言又怎样改变思考和社会？
- 人为什么讲故事，文学为什么能虚构却仍然告诉我们真相？
- 人怎样面对死亡、苦难、偶然和不可理解之物？
- 什么知识值得相信？怎样区分论证、修辞、证据和权威？
- 社会为何形成法律、国家、等级、市场与革命？
- 人为什么创造艺术，什么使一件东西成为美或成为艺术？
- 历史是怎样发生的，我们又凭什么知道过去？

理科的三本书给你的是地图，这本书给你的是罗盘：它不提供标准答案，而是陪你一遍遍地练习——分析一个观点的前提、证据和隐藏假设；区分事实陈述、因果解释、价值判断和立场表达；面对新闻、短视频和网络争论时，主动追问来源、语境和替代解释。说到底，这本书想帮你成为一个**能独立思考、有自己观点的人**。

它也不做这些事：不做名人名言和年代的记忆手册；不宣扬或反对任何一种宗教、制度或立场；不用"东方重感悟、西方重理性"这类方便口号概括复杂传统；不把历史写成从"落后"必然走向"现代"的单线升级故事；也不假装所有观点都同样有证据、同样合理。

## 全书结构

三册、十二篇、114 章，一条时间主线配六副观察镜头（语言、文学、宗教、哲学、历史与美学）：

- **第一册 会说话、会讲故事的人**——如何研究人类世界；语言：人类共同发明的看不见工具；文学：人为什么用虚构寻找真实；从篝火到城市：早期人类世界
- **第二册 神圣、理性与秩序**——古典时代的多种答案；宗教：人如何与神圣相遇；哲学：把理所当然变成问题；相连的中古世界
- **第三册 现代世界与美的追问**——海洋、印刷与新的世界图景；革命、工业与现代社会；美学：什么是美，什么是艺术；数字时代与共同未来

时间主线：人类演化 → 语言与仪式 → 农业与城市 → 文字与国家 → 古典文明 → 世界宗教与哲学传统 → 跨洲交流 → 海洋扩张 → 科学、启蒙与革命 → 工业化、民族国家与帝国主义 → 世界大战与去殖民化 → 全球化、数字时代与人工智能。
