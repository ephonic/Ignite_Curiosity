# 章节写作与 LaTeX 规范（所有作者必须严格遵守）

你负责为《把数学点着：给初中生的数学世界漫游》撰写一个章节文件。这是一本面向初中生的数学科普书。

## 输出要求

- 输出**只有一个 LaTeX 文件**，写到指定路径，文件以 `\chapter{...}` 开头（附录文件以 `\chapter{...}` 开头即可）。
- **绝对不要**写 `\documentclass`、`\usepackage`、`\begin{document}`、`\end{document}` 等导言区内容——文件会被 `\include` 进主文件。
- 全章正文 **6000–9000 个汉字**（不含公式和代码），内容充实，不能写成提纲式短文。
- 语言：简体中文，先讲问题再讲术语，先给图景再给符号；允许读者暂时不懂，但要说明难点在哪。

## 每章固定结构（9 个环节）

1. **一个具体场景**：游戏、建筑、密码、天文、交通或日常观察开篇（`\section{...}` 不必用环节名，自己起生动的节名，但内容要覆盖这些环节）。
2. **一个卡住人的问题**：让读者能先凭直觉猜。
3. **第一次尝试与失败**：展示反例、误区或不够精确的说法。
4. **发明新概念**：说明为什么需要这个定义。
5. **一个核心定理**：用图、例子和短证明说明结论（证明用 `\begin{proof}...\end{proof}`）。
6. **换一个视角**：把本章概念连接到另一门数学或现实应用。
7. **数学实验**：手算、画图、纸牌、尺规、表格或短程序（用 `shiyan` 盒子）。
8. **思考题**：`\section*{思考题}`，分“观察题 / 证明题 / 挑战题”三层，各 1–2 题，**只给提示不给答案**。
9. **通往下一章的门**：`\section*{通往下一章的门}`，留下一个自然产生的新问题。

## 可用的 LaTeX 环境（主文件已定义，直接使用）

- 定理类：`\begin{dingyi}...\end{dingyi}`（定义）、`\begin{dingli}...\end{dingli}`（定理）、`\begin{li}...\end{li}`（例）、`\begin{tuilun}...\end{tuilun}`（推论）、`\begin{zhu}...\end{zhu}`（注）。
- 视觉盒子（每章至少各用一次 toolbox / fanli / lianjie / shiyan / pandeng）：
  - `\begin{toolbox}...\end{toolbox}` —— 数学工具箱：总结本章新工具。
  - `\begin{fanli}...\end{fanli}` —— 反例警报：看似合理但错误的说法。
  - `\begin{lianjie}...\end{lianjie}` —— 连接线：与前文/后文/现实的联系。
  - `\begin{shiyan}...\end{shiyan}` —— 一分钟实验：读者可在纸上或家中完成。
  - `\begin{pandeng}...\end{pandeng}` —— 继续攀登：高中、大学或竞赛层面的延伸关键词。
  - `\begin{shuyu}{术语名}...\end{shuyu}` —— 术语卡片：直观解释、正式定义、一个例子。每章 1–3 张。
- 列表：`itemize`、`enumerate`；数学：`$...$`、`\[...\]`、`align` 环境；表格：`tabular` + `booktabs`（`\toprule/\midrule/\bottomrule`）。

## 图示

- 可以用 `tikz` 画简单示意图（数轴、三角形、函数草图、图论小图等），每章 1–3 幅。保持简单：`grid`、`draw`、`node`、`circle`、`axis` 不要用 `pgfplots`（不一定装了）。tikz 坐标控制在 ±8 以内，图片外层用 `\begin{center}`。
- 不确定 tikz 代码能否编译时，宁可简化。

## 语言与叙事原则

- 每引入一个新符号，说明它解决了什么麻烦。
- 证明写成可追踪的推理，不用“显然”“容易看出”掩盖关键步骤。
- 每个重要公式配一个数值例子或几何解释。
- 未解决的问题明确标“猜想”，近似和直觉标明适用边界。
- 不把数学家写成只会计算的人，可以提他们的猜测、失败、争论和审美。
- 禁止出现真实人名的错误事实；不确定就泛称“数学家们”。

## 编译安全红线（违反会导致全书编译失败）

- 只用上面列出的环境和标准 amsmath/tikz 命令；**不要**自行 `\newcommand` 或 `\usepackage`。
- 正文中的特殊字符 `% & # _` 必须转义为 `\% \& \# \_`。
- 不要引用其他章的标签；不要使用 `\label/\ref` 跨文件引用（本文件内部可以用）。
- 所有数学符号放在 `$...$` 或 `\[...\]` 内。
