# 烧掉物理公式书（暂定名）

> 一本从初中知识出发，不回避现代物理，却始终先讲"为什么"的物理书。

本书与 [`math/`](../math/) 数学卷共享同一套写作哲学：**公式不是物理学的围墙，而是我们把好奇心说得足够准确之后，自然长出来的语言。** 每个新概念先从可观察的现象、实验或思想冲突开始；每条重要公式都回答四个问题——它描述什么、为什么这样写、何时成立、何时失效；数学只在物理问题需要它时出现，先给直觉，再给符号。

- **成品 PDF**：[`phybook/main.pdf`](main.pdf)（676 页，XeLaTeX 编译，可直接阅读）
- **全书提纲**：[`phybook/outline.md`](outline.md)（定位、写法规范、完整目录、例子库、概念准确性护栏）

| | 篇二 经典力学 | 5–12 | 运动描述、牛顿三定律、生活中的力、万有引力、能量、动量、转动、流体 |

每章的固定结构（十步）：

1. **反常识开场**——一个能亲自观察却不容易解释的现象；
2. **先猜一猜**——让读者明确自己的直觉预测；
3. **动手实验**——纸杯、弹簧、磁铁、手机、手电筒等常见物品；
4. **旧模型遇到麻烦**——已有观念为什么不够用；
5. **发明新概念**——像历史上的物理学家一样创造定义；
6. **一句话模型**——最短语言说清本章核心；
7. **数学翻译器**——把直觉翻译成图像、比例、方程或微积分；
8. **模型的边界**——假设、适用范围和典型误用；
9. **回头解释开场现象**——检验新模型是否真的有用；
10. **脑洞实验与挑战题**——重推理、轻计算，附思路提示。

三层阅读标记用彩色盒子区分，读者可以在任何一层停下：

- **主线层**（绿）：只要求初中数学，保证故事完整；
- **数学桥层**（蓝）：引入向量、函数、极限、导数、积分和简单微分方程；
- **挑战层**（红）：线性代数、偏微分方程、复数等，不作为理解后文的硬门槛。

## 写作护栏（全书严格执行）

严格区分"实验事实""数学模型"和"物理解释"，不把任何一种诠释冒充事实。不说"物体需要力才能维持运动"；不把向心力列为新力种；不把熵简单定义为混乱程度；不把不确定性原理归因于仪器粗糙；不把量子测量说成意识创造现实；不把纠缠描述为超光速传信……完整清单见 [`outline.md`](outline.md) 第七节。

## 如何编译

引擎必须是 **XeLaTeX**（中文 ctex 支持），连续编译两遍以生成目录与书签：

```bash
cd phybook
xelatex main.tex
xelatex main.tex
```

依赖宏包：`ctex`（fandol 字体集）、`tcolorbox`、`tikz`、`enumitem`、`booktabs`、`hyperref`（TeX Live full / MiKTeX 全量安装自带）。无需外部图片，全部插图为内嵌 TikZ。

**Overleaf**：把 `phybook/` 下所有 `.tex` 文件上传（保留 `chapters/` 子目录），Menu → Compiler 选 **XeLaTeX** 即可。
