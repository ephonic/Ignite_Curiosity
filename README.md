# After Burning the Books（烧掉数学书之后）

> 一本写给初中生的"高等数学"科普书：**用初中生已经会的数学，把抽象代数、代数几何、微分几何、分析、初等数论、解析数论这六座大厦重新发明一遍。**

本书仿照 Jason Wilkes《烧掉数学书》（*Burn Math Class*）的写作哲学——**数学不是被发现的，是被发明的；看不懂定义，就自己造一个**。全书不预设任何高中或大学知识：缺什么工具（对数、三角函数、复数……）就在书里现场自造，每个吓人的术语出场之前，都先顶着一个"土名字"干活。

- **成品 PDF**：[`math/main.pdf`](math/main.pdf)（187 页，XeLaTeX 编译，可直接阅读）
- **全书提纲**：[`math/outline.md`](math/outline.md)
- **LaTeX 源码**：[`math/`](math/) 目录

## 这本书讲什么

| 篇 | 章节 | 主题 | 从哪开始玩 |
|---|---|---|---|
| 序章 | 0 | 如何烧掉一本数学书 | 自己发明一种运算 $a \heartsuit b = a+b+1$ |
| 篇一 数的骨架：**初等数论** | 1–6 | 同余、辗转相除、素数、反证法、中国剩余定理、费马小定理与 RSA | 今天星期六，$10^{100}$ 天后星期几？ |
| 篇二 运算的规律：**抽象代数** | 7–12 | 群、群表、拉格朗日定理、环与域、多项式、尺规作图不可能性 | 钟表世界里 $2\times 5$ 为什么等于 $0$ |
| 篇三 变化的艺术：**分析** | 13–19 | 极限（刘徽割圆术）、导数、积分、微积分基本定理、$\mathrm{e}$ 与 $\ln$ | 一瞬间的速度是 $0\div0$ 吗？ |
| 篇四 当数论遇见分析：**解析数论** | 20–24 | 素数普查、调和级数、欧拉乘积、素数定理、$\zeta$ 与黎曼猜想 | $1+\tfrac12+\tfrac13+\cdots$ 加得拢吗？ |
| 篇五 弯曲的空间：**微分几何** | 25–28 | 曲率、测地线、高斯绝妙定理、非欧几何与宇宙的形状 | 贴着薯片爬的蚂蚁测得出世界是弯的吗？ |
| 篇六 方程的风景：**代数几何** | 29–32 | 交点算术、贝祖定理、射影平面、椭圆曲线上的群 | 两条抛物线最多交几个点？ |
| 尾声 | 33 | 数学之网 | 收网：六篇之间如何互相供弹 |

每章的固定栏目（全部有彩色盒子）：

- **开胃问题**——5 分钟能上手的真问题，先玩后读；
- **发明时刻 / 发明词典**——本章被迫发明了什么，土名对应大学里的哪个正式术语；
- **动手实验**——分级习题：★ 思考、★★ 计算、★★★ 烧脑（选做）；
- **烧脑时刻**——通往下一章或通往未解之谜的选做挑战；
- **诚实声明**——本书在哪里偷了懒、铺了地毯、只陈述未证明，明明白白交代。

## 三条阅读路线

- **速通线**（快速尝到"高数"的味道）：序章 → 第 1、5、7、15、17、23、27、32 章 → 尾声
- **数论线**（喜欢整数与密码谜题）：篇一 → 第 7–11 章 → 篇四
- **几何线**（喜欢图形与空间）：篇三 → 篇五 → 篇六，回看第 8 章

## 如何编译

引擎必须是 **XeLaTeX**（中文 ctex 支持），连续编译两遍以生成目录与书签：

```bash
cd math
xelatex main.tex
xelatex main.tex
```

依赖宏包：`ctex`、`xecjk`、`zhnumber`、`tcolorbox`、`environ`、`trimspaces`、`everysel`、`multirow`（TeX Live full / MiKTeX 全量安装自带）。

**Overleaf**：把 `math/` 下所有 `.tex` 文件上传（保留 `chapters/` 子目录），Menu → Compiler 选 **XeLaTeX** 即可。

成品约 187 页；书签、彩色栏目盒子、5 幅 TikZ 插图均内嵌，无需外部图片。

## 内容约定（写给想继续扩写的人）

1. 正式术语在"发明时刻"之前不得出现——先用土名（落脚点、瞬间变化率、堆积、绷紧的线……）干活；
2. 正文推导不得超出"初中数学 + 本书已发明的工具"；确需跳步的放进"诚实声明"或旁注；
3. 全书默认读者只掌握：四则运算、乘法公式、一元二次方程与判别式、坐标系、一次/二次函数图像、三角形内角和；
4. 每章 5000–8000 字，开胃问题 → 正文 → 发明时刻 → 动手实验 → 烧脑时刻 → 诚实声明。
