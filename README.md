# 点燃好奇心（Ignite Curiosity）

> 一套写给初中生的学科漫游书：从初中知识出发，一路走到整座学科大厦的门口。

## 这套书是怎么来的

今年，看到儿子在读Jason Wilkes 的《烧掉数学书》（*Burn Math Class*），被它的想法击中：**数学不是被发现的，是被发明的；看不懂定义，就自己造一个。** 一本书可以不从"你应该会什么"出发，而是从一个真实的问题出发，让读者亲手把概念重新发明一遍。忽然很想把这套写书哲学搬到更多的学科里去——物理、化学与生物，再加一本讲人类世界的博雅书。当然数学我也想让它直通整个数学大厦，所以我也重写了。每一本都只做一件事：**从初中课本的最后一页出发，把整座学科大厦的轮廓点亮给你看**。不堆砌术语，不假装深奥，每一个概念登场之前，先让你看到它背后那个真实的问题。

说实话，这套书最初是为我儿子写的。至于有没有点燃他——大概率是失败了。点燃好奇心这件事，从来急不得，也勉强不来。

那就把这几本书分享出来吧。分享给需要它们的人，也分享给九十年代读高中时的我自己。

那时候我在一个小县城，对物理很感兴趣。我跑遍了县城里所有的书店，把每个书架的角落都翻遍了，也找不到一本大学物理教材。我想，那个在书店里打转的少年，如果拿到这样一套从初中知识直通学科大厦的书，应该会很喜欢，会读得眼睛发亮。

这套书是写给他的，也是写给每一个和他一样、对世界怀着滚烫好奇心、却够不到下一级台阶的孩子。
