# 烧掉文科书：初中生的博雅书

> 一本写给初中生的人文博雅书：**人为什么说话、讲故事、相信神圣、追问真理、建立国家、发动革命，又为什么会被一首诗、一座废墟或一段旋律打动？**

这不是把语文、历史、政治、美术课重新装订在一起，而是追踪几个贯穿人类历史的问题：语言怎样改变思考，虚构为什么能说出真相，人怎样面对死亡与偶然，什么知识值得相信，社会为何形成法律与革命，什么使一件东西成为美。全书沿一条时间主线（人类演化 → 语言与仪式 → 农业与城市 → 文字与国家 → 古典文明 → 世界宗教与哲学 → 跨洲交流 → 海洋扩张 → 科学、启蒙与革命 → 工业与帝国 → 世界大战与去殖民化 → 全球化与人工智能），使用六副观察镜头：**语言、文学、宗教、哲学、历史与美学**。

## 每章的固定结构

每一章都按同一副骨架展开（提纲规定，全书一致）：

1. **拿起一件东西**——一块石器、一枚硬币、一条"在吗"的消息开场；
2. **进入一个现场**——先置身于集市、神庙、法庭、客厅或战壕；
3. **提出真正的问题**——不先给结论，让冲突显现；
4. **听见多种声音**——统治者与普通人、胜者与败者、中心与边缘；
5. **思维桥梁**——学一个可迁移的工具（来源五问、论证图、文本细读……）；
6. **阅读一小段证据**——只引公有领域的真实原始材料，注明出处；
7. **比较解释**——同一事实的不同（且不等价）解释，各说理由与局限；
8. **深入挑战**——通往语言学、叙事学、史学、伦理学或美学理论；
9. **回到今天**——这个旧问题在校园、家庭、城市和网络中的回声；
10. **留一个没有标准答案的问题**——要求给出理由，而不是猜作者立场。

写作红线：不虚构引文与数据；区分"发生了什么／为什么发生／当时的人怎样理解／我们怎样评价"；解释一种制度不等于为它辩护；不用"东方感悟、西方理性"之类的口号抹平传统之间的差异（完整约定见 [`WRITING_GUIDE.md`](WRITING_GUIDE.md)）。

## 三条阅读路线

- **方法线**（先学怎么思考）：第一篇 → 第 57–67 章（哲学篇）→ 附录设计章

## 如何编译

引擎必须是 **XeLaTeX**（中文 ctex 支持），连续编译两遍以生成目录与书签：

```bash
cd liberal_arts
xelatex main.tex
xelatex main.tex
```

依赖：`ctex`（`fontset=fandol`）、`booktabs`、`tabularx`、`hyperref`（TeX Live 2020+ 自带 fandol 字体，无需系统中文字体）。

修改某一章后重建全书的流程：编辑 `chapters/chNNN.md` → `python gen_tex.py` 生成 `main.tex` → 按上面命令编译。

## 内容约定（写给想继续扩写的人）

1. 每章 8,000–10,000 字，十个结构环节齐全，"思维桥梁"与"深入挑战"小节按此命名；
2. 原始材料只引确信真实的公有领域文本并注明出处，没有把握就转述并写明"大意是"；
3. 四种内容分清：发生了什么／为什么发生／当时的人怎样理解／我们怎样评价；
4. 章节文件只用 Markdown（`##` 小节、粗体、列表、引用块、简单表格），不写 LaTeX 命令；
5. 主线语言要让初二学生能独立读懂，术语首次出现必须配生活化例子。
